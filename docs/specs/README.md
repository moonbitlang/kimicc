# Language Specifications Reference

This directory contains language specification documents for reference when working on the kimicc compiler.

## C Language Specification

- **c11-n1570.pdf** — ISO/IEC 9899:2011 (C11) draft standard (N1570).
  This is the primary reference for C grammar, semantics, and standard library.
  Downloaded from: https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf

## MoonBit Language Documentation

The following HTML pages are from the MoonBit official documentation
(https://docs.moonbitlang.com/en/latest/language/):

- **moonbit-index.html** — Documentation index
- **moonbit-introduction.html** — Language introduction and basic syntax
- **moonbit-fundamentals.html** — Core language features (types, control flow, etc.)
- **moonbit-methods.html** — Methods and traits
- **moonbit-ffi.html** — Foreign Function Interface (C interop)
- **moonbit-attributes.html** — Attributes and annotations
- **moonbit-error-handling.html** — Error handling patterns
- **moonbit-packages.html** — Package system and modules
- **moonbit-tests.html** — Testing framework
- **moonbit-derive.html** — Derive macros
- **moonbit-async.html** — Async/await experimental features
- **moonbit-verification.html** — Proof and verification features

## Notes

- The C11 spec (N1570) is the freely available draft; the official standard
  requires purchase from ISO.
- MoonBit documentation is downloaded as static HTML for offline reference.
  Open any `.html` file in a browser to read.
